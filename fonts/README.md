# SynItArt Sans v1.0 (Tunnel)

SynItArt 그룹 공용 영문·숫자·기호 서체. 한글은 Pretendard(OFL 1.1)가 이어받는다.

- 파일: `SynItArtSans-Regular.woff2`(400), `SynItArtSans-Bold.woff2`(700), `synitart-sans.css`
- 199자: 영문 대소문자, 숫자(고정폭), ASCII 문장부호, Latin-1 강세 글자, ₩ € ™ © ® · ※ → ▲ ▼ ✓ 등
- 글꼴 스택: `"SynItArt Sans","Pretendard Variable","Pretendard",<기존 대체 글꼴>`
- 저시력 기준: l·1·I·0·O·8·B·a·o를 서로 다른 모양으로 설계(흐림 시뮬레이션 9쌍 모두 기존 Noto Sans KR 900보다 구분도 높음)
